# 工事写真・現場写真 保存フォルダ

ここに現場写真や施工中、完成写真を保存してください。
形式: .jpg, .jpeg, .png, .webp

## 推奨ファイル名（例）
- `step01_survey.jpg` （現地調査・地縄・敷地確認）
- `step02_foundation.jpg` （基礎工事・配筋・型枠・コンクリート打設）
- `step03_framing.jpg` （建て方・木造軸組・金物工法・梁現し）
- `step04_roof_wall.jpg` （ガルバリウム鋼板屋根・外壁透湿防水シート）
- `step05_shutter_doors.jpg` （シャッター・サッシ・建具取付）
- `step06_interior.jpg` （内部造作・特注棚・土間コンクリート仕上）
- `step07_complete.jpg` （完成外観・愛車入庫・夜間照明等）

※ファイル名がバラバラでもAI側で判別して組み込みますので、そのままUPいただいて問題ありません。
