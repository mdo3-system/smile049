# スマイチ 木造ガレージ 見積書ロジック改正計画書 ＆ 差異分析レポート

- 発行日: 2026年11月13日
- 対象システム: スマイチ（smile049.jp）3Dシミュレーター精密積算エンジン (`src/simulator/pricing/costEstimator.js`)
- 報告先: 経営陣・設計・工務・営業チーム

---

## 1. 改正の背景・目的

従来の積算ロジックは、石井様邸（17㎡）および三愛メモリアル様（36㎡）の実績値をベースに線形按分を行っておりました。
しかし、現場実績との照合において以下の乖離および漏れが判明したため、適正利益の確保と実態に即した積算体系への改正を行います。

1. **石井様邸（17㎡基準）の木部材料費の乖離**:
   - 当初算定: 41.7万円（システム登録値 420,000円）
   - **実績値: 43.9万円（439,000円）** ［+22,000円の増額］
2. **石井様邸（17㎡基準）の建材費（天井施工）の乖離**:
   - 当初算定: 5.8万円（システム登録値 60,000円）
   - **実績値: 8.2万円（82,000円）** ［+24,000円の増額（天井張り施工に伴う下地・ボード増）］
3. **木工事の施工費（大工手間）の計上漏れ解消**:
   - 石井様邸・三愛メモリアル様ともに材料費のみで施工費が漏れていた。
   - **改正後**: 床面積に応じた4段階ステップ制（50㎡以下: 12万円、100㎡以下: 16万円、150㎡以下: 20万円、150㎡超: 別途見積もり）を新設導入。

| 項目 | 現行ロジック | 新ロジック (改正後) | 差異 / 改正内容 |
| :--- | :--- | :--- | :--- |
| **基準原価 (17㎡・石井様)** | 420,000円 (41.7万) | **439,000円 (43.9万円)** | +19,000円 (実質+2.2万円増額) |
| **基準原価 (36㎡・三愛様)** | 620,000円 (62.0万) | **620,000円 (62.0万円)** | 変更なし |

| **木工施工費 (大工手間)** | **0円 (未計上・漏れ)** | **〜50㎡: 120,000円 (12万)<br>〜100㎡: 160,000円 (16万)<br>〜150㎡: 200,000円 (20万)<br>150㎡超: 別途見積もり** | **規模別ステップ制施工費を新設導入** |

### 分析ポイント
1. **主力ゾーン（17㎡〜36㎡ / 約5坪〜11坪）の健全化**:
   - これまで大工施工費が未計上だったため、1台用ガレージで約16万円、2台用で約12万円の原価漏れ（粗利圧迫）が発生していました。
   - 改正により、販売見積価格は約16万〜21万円（税込約17.5万〜23.5万円）適正に引き上げられ、確実に粗利約25%が残る健全な価格設定となります。
2. **150㎡以上の特注扱い化**:
   - 150㎡以上の大スパン建築は構造計算（許容応力度計算）や特殊トラス・大断面集成材が必要となるため、自動按分ではなく「別途見積もり」とすることで、過小積算トラブルを未然に防止します。

## 4. システム修正計画（対象ファイル・作業工程）

1. **`src/simulator/pricing/costEstimator.js` の改修**:
   - `costWood` を「木部材料原価 + 木工施工費」に分離計算。
   - `floorAreaM2 > 150` の場合に `isCustomQuoteRequired: true` フラグを付与。
   - 木部・建材の基準原価（石井様邸 43.9万 / 8.2万）および新傾きを適用。
   - 見積明細アイテムの内訳テキスト（`calcBasis`）を最新仕様に更新。
2. **`src/components/EstimateDetailModal.jsx` の表示改修**:
   - 木工事の内訳として「構造部材一式」と「大工施工費（床面積ステップ制）」の明細を綺麗に表示。
   - 150㎡超の場合は「150㎡超のため別途特注お見積り」のバッジを表示。
3. **ビルド検証・テスト**:
   - 17㎡、36㎡、50㎡、100㎡、160㎡の各モデルで期待通りの原価・見積額が計算されることを検証。
4. **本番デプロイ**:
   - エックスサーバーへの反映。
